# Robot character

`robot.png` was generated with the built-in image generation tool for this interface.
The transparent image is the shell and body; `ui/app.js` draws and animates the eyes
independently so the character responds to the assistant's actual state.

Final generation prompt:

> Use case: stylized-concept. Asset type: transparent PNG character asset for a desktop assistant with separately animated eyes. Reference: the user attached a cute cinematic robot with a pearl white rounded helmet, a glossy black face visor, cyan LED eyes, and a small body. Create a premium 3D rendered character inspired closely by this shape and materials. Centered symmetrical straight-on front view, entire head plus torso and two small relaxed arms, lower body neatly rounded and fully visible. Large domed rounded triangular pearl ceramic helmet, broad BLACK EMPTY visor occupying the center of helmet, no eyes, no mouth, no graphics inside the visor because eyes will be drawn in code. Wide helmet with a softly flattened bottom; small rounded white body below with graphite joints and a tiny cyan chest light. Premium Pixar-quality physically based materials, soft silver reflections, bright white rim highlights, subtle cyan underlighting, charming proportions. Camera at face height, very little perspective. Subject fills 90 percent of a square image, generous 5 percent transparent border, no background, no ground plane, no shadow beyond character. No text, no logo, no antenna, no human facial features. The entire visor MUST remain deep black and empty. Single robot only.
